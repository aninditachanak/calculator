# 🧮 Calculator

A simple and user-friendly calculator application designed to perform basic arithmetic operations with a clean and responsive interface.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- 🔢 Decimal number support
- 🧹 Clear and reset functionality
- 📱 Responsive user interface
- ⚡ Fast and easy to use

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask
